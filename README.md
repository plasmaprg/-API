# Playwright API CRUD Tests

Автотесты полного жизненного цикла сущности (POST, GET, PUT, PATCH, DELETE) на Playwright.

## Конфигурация
Адрес API задается в файле `.env` через переменную `BASE_URL` (по умолчанию `https://api.restful-api.dev`).

## Запуск
1. `npm install`
2. `npm test`
3. `npm run report`
